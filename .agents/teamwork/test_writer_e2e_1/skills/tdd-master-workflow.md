## The Red-Green-Refactor Cycle
- Phase 1: RED (Write failing test)
- Phase 2: GREEN (Make test pass)
- Phase 3: REFACTOR (Improve code maintainability)

## Test Architecture & Standards
- Isolation: Independent tests, mock/stub external dependencies
- Speed: Fast execution
- Coverage: 100% on critical business logic, > 80% line coverage
- Naming: `should_[expected_behavior]_when_[condition]`
