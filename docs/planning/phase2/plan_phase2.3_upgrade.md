# Phase 2.3 — XP feedback and pace validation

Updated: 2026-10-26. This local plan is a scope/reference note, not a separate completion checklist.

Preserve the design goal: immediate estimated feedback while logging, server-authoritative completion, humane handling of short legitimate sessions, and bounded reward for implausible input. Preview feedback must not imply that XP has already been awarded.

Old numerical examples were superseded. Consult the tested progression guide for current caps/curves. Warnings must not pressure users to continue training through pain or injury, and recovery/retry must not duplicate rewards.
