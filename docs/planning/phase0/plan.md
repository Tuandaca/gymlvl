# Phase 0 — setup and infrastructure

Updated: 2026-10-26. This local plan is a scope/reference note, not a separate completion checklist.

Use the current development guide to inspect Flutter/Dart, Supabase CLI, Docker, Deno and supported device prerequisites. Start an isolated backend, apply versioned migrations/seeds, and provide the app with SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY. The legacy SUPABASE_ANON_KEY is a supported compatibility option.

No hosted project or credential is assumed. Client configuration must never contain a secret/service-role key. Local reset is permitted only for disposable local data. Tool availability and execution results belong in the authoritative report.
