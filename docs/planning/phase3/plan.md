# Phase 3 — dashboard and UI polish

Updated: 2026-10-26. This local plan is a scope/reference note, not a separate completion checklist.

Visual direction: dark fitness-RPG HUD with restrained cyan/purple/green, readable data hierarchy, reusable cards/inputs/navigation, clear primary actions and nonblocking progression feedback. Verify phone/tablet/desktop widths, VI/EN, larger text, keyboard focus, safe areas and reduced motion.

Dashboard/profile/quest screens exist. Acceptance covers actual data, loading/empty/error/retry/success states, workout readability and saved settings. Avatar upload and broader badge/quest collections must be reported against implementation rather than inferred from design sketches. Supabase Storage is the prospective upload backend.
